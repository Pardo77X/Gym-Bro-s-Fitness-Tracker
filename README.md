# Gym Bro's Fitness Tracker 💪

This is a full-stack fitness tracking web application built with **Angular** (frontend) and **Spring Boot** (backend). The goal is to allow users to track their daily **weight**, **water intake**, and **step count** through a stylish, responsive interface.

## 🚀 Features

- ✅ Track daily **weight entries** and view history.
- 💧 Log **water intake** in ounces.
- 👣 Save and view **step counts** for each day.
- 🔗 Connected to a **PostgreSQL database** using Spring Boot REST API.
- 💻 Clean UI with color-coded sections for quick recognition.

## 🛠️ Technologies Used

### Frontend:
- Angular 17
- HTML / CSS
- TypeScript

### Backend:
- Spring Boot
- RESTful API
- PostgreSQL
- JPA (Hibernate)

## 📂 Project Structure

-student-app → Angular frontend
-springboot → Spring Boot backend

## 📋 How to Run Locally

1. Clone the repository:
git clone https://github.com/Pardo77X/Gym-Bro-s-Fitness-Tracker?tab=readme-ov-file

2. Open Spring Boot backend in your IDE and run the application.

3. In a separate terminal, run the Angular frontend:

cd student-app

npm install

ng serve
